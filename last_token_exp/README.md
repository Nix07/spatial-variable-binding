# Last-Token Position Patching (Paper Figure 3)

Replicates Figure 3 of the spatial-reasoning analysis — the **last-token
position-patching** experiment on the **Squares** dataset.

For each LM layer `l`, the residual-stream vector at the final ("is") token is
patched from a counterfactual run into a clean run, and the output
logit-probability over five colors is recorded. The transition between
*ordering* layers (patched output = clean image's same-ordinal color) and
*attribute* layers (patched output = counterfactual color) is the load-bearing
observation in the paper.

```
last_token_exp/
├── README.md
├── run_experiment.py             # thin CLI: patch every LM layer, save .npy per model
├── build_cf_pairs.py             # thin CLI: sample tuples, keep only those the model
│                                 # answers correctly on BOTH clean and cf
├── plot.py                       # produce 1×K per-direction figure (per setting)
├── src/
│   ├── data.py                   # VLPrompt + image construction; SETTINGS registry
│   │                             # (squares / shapes / objects / whatsup)
│   ├── filter.py                 # clean+cf top-1 correctness filter
│   └── patch.py                  # run_with_cache + run_with_hooks patching loop
├── cf_pairs/<setting>.json       # 50 five-element tuples per model per direction
│                                 # (each tuple encodes a clean+cf pair)
├── results/<model>/<setting>_final_token.npy
└── figures/<model>/<setting>.{png,pdf}
```

Settings: `squares`, `shapes`, `objects`, `whatsup`. The 4-direction
settings are squares/shapes/objects; `whatsup` is **left/right only**
(the controlled images and floor prompt are horizontal). The answer
token is the color for squares/shapes and the object name for
objects/whatsup.

## Quickstart — regenerate just the figures (no GPU)

```bash
python plot.py                            # all three models, squares
python plot.py qwen2vl --setting shapes   # one model, one setting
```

Requirements: `numpy`, `matplotlib`.

## Full reproduction — rerun patching and plot

The runner imports the repo-root modules (`analysis_utils.py`, `metrics.py`,
`vision_language_prompts.py`, `component.py`) and the vendored TransformerLens.
Run it from the repo root; it injects the paths itself.

### 1 · Set up the parent repo environment

```bash
cd ../..                          # repo root
bash setup.sh                     # installs torch / transformers / TLens deps
huggingface-cli login             # for gated weights (Gemma)
```

### 2 · Rerun the patching for one model

```bash
cd last_token_exp
python run_experiment.py --model qwen2-vl-7b   --cache-dir /path/to/hf_cache
python run_experiment.py --model gemma-3-4b-it --cache-dir /path/to/hf_cache

                         --device-list 0 1 2 3            # 12B needs sharding
```

Useful flags:

| flag                | purpose                                                          |
|---------------------|------------------------------------------------------------------|
| `--n-samples N`     | cap samples per direction (default: 50)                          |
| `--directions left` | only run a subset of directions                                  |
| `--batch-size N`    | override per-model default (qwen=13, gemma=5, pixtral=1)         |

| `--device-list 0 1 2 3` | shard model across multiple GPUs                             |

Each invocation writes `results/<model>/<setting>_final_token.npy`

## Saved-data format

Each `<setting>_final_token.npy` is a pickled `dict[direction → ndarray]`
(`left`, `right`, `above`, `below`; whatsup has only `left`, `right`).
Each array has shape
`(n_samples, n_layers + 1, 1, 5)` of `float32` logit-probabilities, where:

- The layer axis has `n_lm_layers + 1` slots. Slot 0 is `resid_pre` of layer 0
  (the post-embedding residual stream, rendered as the "Embed" tick); slots
  `1..L` are `resid_post` of each LM layer.
- The last axis is the five candidate colors `[clean_pos0, middle,
  clean_pos2, cf_pos2, cf_pos0]` — rendered in the canonical
  Red/Green/Blue/Black/Gray palette used by the paper.

| model            | n_samples | n_layers (slots) |
|------------------|-----------|------------------|
| Qwen2-VL-7B      | 50        | 29               |
| Gemma-3-4b-it    | 50        | 35               |
| Pixtral-12B      |  5        | 41               |

> The Pixtral data shipped here was generated on the `nikhil` branch with only
> 5 samples (wide std bands). Rerun `run_experiment.py --model pixtral-12b`
> to get a 50-sample replication.

## Experimental design

For each five-color tuple `(c₀, c₁, c₂, c₃, c₄)` and direction `d`:

| pair    | image (positions 0–2)     | prompt direction      | answer   |
|---------|---------------------------|-----------------------|----------|
| clean   | left/above: `(c₀,c₁,c₂)`<br>right/below: `(c₂,c₁,c₀)` | `d`                   | `c₀`     |
| cf      | left/above: `(c₄,c₁,c₃)`<br>right/below: `(c₃,c₁,c₄)` | opposite of `d`       | `c₃`     |

`prob_strs = [c₀, c₁, c₂, c₃, c₄]`. The summed token-probability for each
color (covering `{lower, Capitalize, ' '+lower, ' '+Capitalize}` token
variants) is recorded at the final-token position after patching.

The prompt is identical across all three models (the relevant
processors tokenize it differently):

```
[system] You are a helpful assistant. You respond in one token.
[user]   <image> The color of the square {to the left of / to the right of /
         above / below} the {middle_color} square is
```

## Reading the figure

- **Red** (clean side-0 color) dominates early layers: patching has no effect
  on the clean output. The model is still working from clean-side info.
- **Blue** (clean side-2 color) spikes around layers 20–22 (Qwen):
  these layers carry *ordinal-position* information — patching the
  counterfactual's ordering swaps the model's answer to the clean image's
  same-ordinal color.
- **Black** (counterfactual side-2 color) takes over after layer ~22:
  these layers carry the *attribute* (color value) of the queried square,
  and patching transfers the counterfactual color directly.

Shaded bands are ±1 std across samples.
